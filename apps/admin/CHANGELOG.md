# 更新记录

## 0.5.1 - 2026-09-22

- 新增 MiniMax 官方 Speech 2.8 与 Music 3.0/2.6 接口模板，完善 H3 输入 Token 计费与音频参数映射。
- 完善 OpenAI、Claude、Gemini、GLM、Qwen 等模型的思考参数映射，以及图片、视频、音频多模态输入与线路能力配置。
- 优化第三方 Chat Completions 接入稳定性，完善 502/504、Cloudflare 网关错误识别、超时控制及线路重试切换。
- 优化通用 Agent 与无限画布，新增文档转图片、任务规划与恢复、审核失败降级及多模态工作流能力。
- 优化电商一键出图与商品精修流程，完善工作台及后台的多语言覆盖与翻译管理。

## 0.5.0 - 2026-08-30

- 新增 `Agent 通用智能体`，支持通过连续对话完成图片、视频、语音和音乐创作；支持上传文件、资产库引用、自动选择后台默认模型、自定义生成模型、深度思考、历史恢复及上一轮生成结果连续引用。
- 为 `Agent 通用智能体` 新增智能搜索，支持 Tavily、Brave Search API 与自建 SearXNG；加入可信系统时间、Agent 检索决策、查询改写、新闻/金融主题、时效范围、来源约束、历史恢复、每日限额和失败自动降级。
- 优化智能搜索响应速度：明确联网或无需联网的请求使用本地快速路由，仅模糊追问调用可配置的轻量路由模型，并支持 Redis 短时搜索缓存。
- 增加可选的内置 SearXNG Docker Profile，默认不启动；启用后仅通过容器内网提供 JSON 搜索，并限制 CPU、内存、并发连接和搜索引擎数量。
- 将通用智能体调整到大模型列表首位，多模型协作顺延为第二项；统一 PC 与移动端工作区顶部操作栏，完善通知、语言、用户菜单、新任务和历史功能，并优化移动端能力轮播与输入区布局。
- 新增 AI 试衣间工作流，支持人物与服饰素材上传或资产库引入、模型与清晰度选择、多张生成、历史任务恢复、团队头像和使用说明。
- 新增一键爆款复刻工作流，支持 TikTok、抖音等视频链接导入、参考视频时长识别、片段数与单段时长联动，以及分析、关键帧、视频和音频模型统一选择。
- 完善无限画布与故事短视频链路：支持首节点统一指定四类模型、素材上传和资产库引用、已提交历史与浏览器草稿分离，并支持失败节点保留上下文后继续运行。
- 新增 AI 写真馆并优化 AI 小说工坊，完善新任务、历史记录、深浅色模式、逐步确认、内容版本和模型用量计费。
- 完善聊天、图片、视频、音频与工作流扣费链路，统一预估冻结、成功结算、失败或取消解冻，并补齐缓存 Token、按次、按秒及上游成本配置同步。
- 修复视频模板参考图未真实传参、VEO 首尾帧任务进度停滞、生成时长参数不兼容、历史媒体与素材恢复错误等问题。
- 后台新增第三方在线客服脚本配置，可在现有首页客服与 Chatwoot 等第三方客服之间切换，并保持关闭状态下不向用户端注入脚本。
- 完善数据库迁移校验、登录异常兼容、管理后台空模型列表处理及 GitHub Actions 验证流程。

## 0.4.0 - 2026-08-12

- 新增模型上游线路池：同一平台模型可配置多条上游线路，支持优先级、同级权重分流、快捷启停、自动故障切换、限次重试、熔断冷却与半开恢复探测。
- 完善线路成本与平台售价分离：用户展示和实际扣费统一使用模型 `price_rule`，各线路独立维护上游 Token、按次、按图或按秒成本，并提供近 30 天收入、成本、毛利和调用次数统计。
- 新增线路批量健康检查、异常提醒、最近调用明细、HTTP 状态、错误标识和耗时记录；聊天、图片、视频、音频、智能体及工作流统一接入线路池。
- 支持 OpenAI Chat Completions / Responses、Anthropic Claude Messages 与 Gemini generateContent 原生协议，完善同步、流式和异步任务的线路切换与幂等保护。
- 上游线路 API Key 改为 AES-GCM 加密存储，并兼容已有明文线路；生产环境支持独立配置 `MODEL_ROUTE_CIPHER_KEY`。
- 优化后台模型管理：新增模型表单显示在模型列表上方，编辑表单显示在对应模型行下方；新增模型会自动建立主线路，主线路基础接入字段与模型配置保持同步。
- 重构 API 文档中心，整合聊天与文本、多协议调用及平台工具，完善在线调试、真实模型名、动态站点 API 地址、后台自定义文档融合和多语言显示。
- 完善全站中、英、日、韩、越多语言接入，清理 API 文档、模型工作台、智能体页面及图片、视频、音频页面的大量硬编码中文。
- 修复本地与线上 API 文档在线调试地址错误、前端 HTML 404、跨域请求提示、聊天模型无响应，以及订单筛选后分页总数不准确等问题。

## 0.2.0 - 2026-07-11

- 新增 Stripe、PayPal 与通用收银台真实在线支付，订单先进入待支付状态，仅在服务端验签回调成功后原子入账，并支持回调防重放、金额与币种校验。
- 收紧模拟支付安全边界：仅 `APP_ENV=development`、`local` 或 `test` 可即时模拟到账；`production`、`staging`、空值及未知环境全部禁止模拟支付，支付资料不完整时前台自动停用在线充值。
- 完善在线支付后台配置，包括渠道启停、币种、金额范围、回跳地址、Webhook 密钥、Stripe 密钥及 PayPal 沙箱/正式环境参数。
- 新增中、英、日、韩、越五语言支持，统一静态 UI 词典与模型、智能体、工作流、开放 API 文档等动态内容翻译链路。
- 新增后台 AI 生成缺失 UI 翻译、翻译模型测试、历史内容补翻、失败原因记录与一键重试；新建或修改内容可在后台异步翻译，不阻塞保存发布。
- 动态译文按“人工覆盖 → 目标语言译文 → 英文译文 → 中文原文”回退，语言切换直接读取已保存译文，不会在每次切换时重复调用翻译模型。
- 优化智能体工作台多语言布局，长标题、描述和标签使用保留边框的省略显示，修复卡片重叠、输入区错位及移动端进度展示问题。
- 完善部署与安全检查：本地开发使用 `.env.local`；生产部署对弱 JWT 密钥提供醒目告警但不阻断一键体验，并补充迁移校验与预发布验证流程。

## 0.3.0 - 2026-07-30

- 完善 AI 漫剧完整创作链路，补充项目记录、角色/道具/场景资产、关键帧、视频分段、配音及最终视频合成与展示。
- 优化 AI 漫剧模型与计费配置，支持选择对话、图片、视频和音频模型，并完善失败重试、生成进度、参考素材及角色一致性处理。
- 新增无限画布工作台，支持文本输入、文本生成、图片生成、视频生成、音频生成和合成节点自由编排与连接。
- 完善无限画布模板库、空白画布、历史画布、导入导出、资产库引用、节点预览/复制/下载及移动端操作体验。
- 无限画布节点参数跟随所选模型动态变化，统一工作流运行、生成进度、错误展示与算力扣费链路，并补充 Seedance 2.0 等视频模型能力。
- 修复“故事短视频”仅生成单个片段的问题，新增 3/4/6/8 段故事长度配置、多关键帧连续生成、多视频片段生成、旁白配音与最终顺序合成。
- 重构无限画布“爆款复刻”链路，分离爆款参考与品牌素材，支持多模态结构分析、3/4/6 段关键帧与视频生成、9:16 参数下发和最终顺序合成。
- 新增“一键视频高清”专用工作流，支持上传或引用视频资产、720P/1K/2K AI 超分、均衡/细节/降噪模式、保留原音、实时进度、失败重试、历史记录、结果预览下载和模型实际计费；后台可管理超分模型、清晰度、文件限制及默认参数。
- 新增“一键转绘”商业工作流，支持视频与风格参考图资产、风格强度、动作/人物/原音一致性控制、真实视频转视频模型、任务进度、结果预览下载与模型实际费用结算。
- 新增“一键去字幕”商业工作流：自动检测独立字幕轨并由 FFmpeg 无损移除，画面硬字幕自动切换到后台指定的 AI 修复模型；支持字幕区域、水印保护、真实处理路径和费用展示，缺少修复模型时明确失败而不伪造成功。
- 将无限画布“爆款复刻”升级为可独立启停和管理的智能体工作流；进入后自动载入爆款参考、品牌素材、多模态拆解、原创关键帧、多段视频与最终合成链路，并与普通无限画布隔离历史记录。
